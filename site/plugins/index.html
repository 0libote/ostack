TokenEconomizer

Cost

Spend fewer tokens in familiar repos

Experience-driven cost control for coding agents: learns repository facts, prunes unused tools where supported, and intervenes in failure loops. Measured 18–30% lower cost on SWE-Bench tasks.

Upstream source

Plugins differ from skills. Skills are Markdown instructions copied or linked into your harness folders. Plugins are installed by each agent’s own plugin tooling and stay upstream; ostack documents them but does not copy them into skills/.

Install TokenEconomizer

You need Python 3.10+ on PATH and one supported agent. Keep the clone in place: Claude Code, Codex, the Copilot CLI, and opencode run the plugin from the clone.

Claude Code

git clone https://github.com/microsoft/TokenEconomizer.git
claude plugin marketplace add "$PWD/TokenEconomizer"
claude plugin install tokeneconomizer@tokeneconomizer

Start claude, trust the folder, and run /tokeneconomizer:status. Once per machine, and again after Claude Code updates, run /tokeneconomizer:toolprune refresh-catalog.

Codex

git clone https://github.com/microsoft/TokenEconomizer.git
codex plugin marketplace add "$PWD/TokenEconomizer"
codex plugin add tokeneconomizer@tokeneconomizer

Start codex, choose Trust and continue, then Trust all and continue at the hooks review. The hooks take effect from your next session, so quit, start codex again, and check with $tokeneconomizer:status.

OpenCode (experimental)

git clone https://github.com/microsoft/TokenEconomizer.git
mkdir -p ~/.config/opencode/plugins
ln -s "$PWD/TokenEconomizer/plugin/opencode/tokeneconomizer.ts" ~/.config/opencode/plugins/

Start opencode, send a prompt, then check with ~/.tokeneconomizer/bin/te --host opencode status. Upstream lists this support as experimental.

t3code-docker

Install inside the container as t3 so the clone and Codex configuration live on the persistent /home/t3 volume:

docker compose exec -u t3 t3code bash -lc 'git clone https://github.com/microsoft/TokenEconomizer.git "$HOME/.local/share/TokenEconomizer"'
docker compose exec -u t3 t3code bash -lc 'codex plugin marketplace add "$HOME/.local/share/TokenEconomizer" && codex plugin add tokeneconomizer@tokeneconomizer'

Restart Codex sessions after installation. Update with git -C ~/.local/share/TokenEconomizer pull inside the container.

Update

git pull

Run git pull in the clone (plus the codex plugin add line again for Codex). The upstream README documents other agents, troubleshooting, and every setting.

What it does

  • Micro-skills. Remembers how the repository works from repeated failures and a review every three sessions. Off by default.
  • Tool pruning. Leaves out tools that go unused, through each agent’s own settings. On by default.
  • Failure-loop intervention. A judge model redirects turns that look stuck, at most once per turn. On by default.

What it learns stays on your machine in ~/.tokeneconomizer. Apache-2.0. See the upstream repository for supported versions, full settings, and the paper’s results.
