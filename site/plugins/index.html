TokenEconomizer

Cost

Spend fewer tokens in familiar repos

Experience-driven cost control for coding agents: learns repository facts, prunes unused tools where supported, and intervenes in failure loops. Measured 18–30% lower cost on SWE-Bench tasks.

Vendored copy

Plugins differ from skills. Skills are Markdown instructions copied or linked into your harness folders. Each plugin is vendored under plugins/ in this repository and updated from upstream through the same sync workflow as the skills, so install from the local copy below instead of cloning upstream yourself. The upstream repository remains the source of truth.

Install TokenEconomizer

You need Python 3.10+ on PATH and one supported agent. Install from an ostack checkout and keep the checkout in place: the agents run the plugin from the vendored path.

git clone https://github.com/0libote/ostack

Claude Code

claude plugin marketplace add "$PWD/ostack/plugins/tokeneconomizer"
claude plugin install tokeneconomizer@tokeneconomizer

Start claude, trust the folder, and run /tokeneconomizer:status. Once per machine, and again after Claude Code updates, run /tokeneconomizer:toolprune refresh-catalog.

Codex

codex plugin marketplace add "$PWD/ostack/plugins/tokeneconomizer"
codex plugin add tokeneconomizer@tokeneconomizer

Start codex, choose Trust and continue, then Trust all and continue at the hooks review. The hooks take effect from your next session, so quit, start codex again, and check with $tokeneconomizer:status.

OpenCode (experimental)

mkdir -p ~/.config/opencode/plugins
ln -s "$PWD/ostack/plugins/tokeneconomizer/plugin/opencode/tokeneconomizer.ts" ~/.config/opencode/plugins/

Start opencode, send a prompt, then check with ~/.tokeneconomizer/bin/te --host opencode status. Upstream lists this support as experimental.

t3code-docker

Run the same commands inside the container as t3, substituting the container-side path of your ostack checkout so the vendored copy and Codex configuration live on the persistent /home/t3 volume:

docker compose exec -u t3 t3code bash -lc 'codex plugin marketplace add <path-to-ostack>/plugins/tokeneconomizer && codex plugin add tokeneconomizer@tokeneconomizer'

Restart Codex sessions after installation.

Update

git -C ostack pull --ff-only

Plugin updates arrive through the upstream sync, one PR per plugin; pull the checkout to get them (plus the codex plugin add line again for Codex). The upstream README documents other agents, troubleshooting, and every setting.

What it does

  • Micro-skills. Remembers how the repository works from repeated failures and a review every three sessions. Off by default.
  • Tool pruning. Leaves out tools that go unused, through each agent’s own settings. On by default.
  • Failure-loop intervention. A judge model redirects turns that look stuck, at most once per turn. On by default.

What it learns stays on your machine in ~/.tokeneconomizer. Apache-2.0. See the upstream repository for supported versions, full settings, and the paper’s results.
